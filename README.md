# Basic To-Do List Program

This project is a base for a basic to-do list program. Built in Python, it provides a modular framework for managing daily tasks through scripts.

## Features and Project Structure

The application's core functionality is divided into separate Python files, making it easy to maintain and expand:

* **Main Interface:** `menu.py` serves as the primary entry point to interact with the application.


* **Add Tasks:** `add_task.py` handles the creation of new to-do list items.


* **Display Tasks:** `display_task.py` allows users to view their current tasks.


* **Edit Tasks:** `edit_task.py` provides the functionality to modify existing entries.


* **Complete Tasks:** `complete_task.py` processes items marked as finished.


* **Remove Tasks:** `remove_task.py` handles the deletion of tasks from the list.



## Data Storage

The application utilizes flat text files for simple local data persistence:

* **Active Tasks:** Ongoing to-do items are stored in `tasks.txt`.


* **Archived Tasks:** Finished items are moved to or tracked in `completed_tasks.txt`.
